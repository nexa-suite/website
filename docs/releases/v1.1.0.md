# Nexa Website v1.1.0

Released: 2026-08-18

## Summary

API-backed public contact and demo request entry point for the Nexa Website.

## Added

- Functional ES/EN contact and demo request form with client validation, API error handling and success state.
- Website-to-API submission contract for `POST /api/v1/public/contact-requests`.

## Changed

- Current suite release metadata and API runtime labels are aligned with published evidence.
- Local API-origin configuration and claim boundaries are documented without asserting deployment.

## Boundary

The Website remains a static public experience. Persistence, tenant authorization, mobile execution and deployment are outside this release.

## Validation

- Website lint and commit validation passed on the release candidate.
- Static application source and declared routes remain preserved.
