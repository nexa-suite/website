# Nexa Website v1.0.0

Date: 2026-10-05.

Stable release of the bilingual static public website. The release retains the
existing visual design and the UX corrections, legal content and commercial
presentation integrated into the previous main revision.

## Scope

- Public product, company, team, industry, pricing, FAQ and legal information.
- Existing responsive CSS, bilingual copy and lightweight JavaScript behavior.
- GitHub Pages metadata and repository content provenance.
- Informational access guidance; no newly implemented transactional sign-in or
  service-backed contact submission is introduced by this release.

## Compatibility

The static page paths, local assets and existing browser-facing navigation are
preserved. The major version establishes this public-site release boundary;
it does not redefine Nexa business behavior or the API contract.

## Verification

Release validation records JavaScript syntax, local file and fragment references,
configured Markdown lint and published-site reachability. Browser UX acceptance
and acceptance of the complete Nexa system are separate evidence.
