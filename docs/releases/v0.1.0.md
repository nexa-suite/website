# Nexa Website v0.1.0

Released: 2026-07-22

## Summary

Initial static commercial website baseline for Nexa's B2B cold-chain product.

## Added

- Semantic HTML5 pages for product, solutions, team, pricing, FAQ and legal content.
- CSS3 design tokens, responsive layouts and reusable visual patterns.
- Vanilla JavaScript for language selection, navigation interactions, animation and pricing contact behavior.
- ES/EN content dictionaries.

## Runtime

The repository is served as static files. No backend, database, API integration, AI, IoT, mobile client or external cloud service is included in this release.

## Known limitations

Public copy may describe future Nexa capabilities, but those descriptions are not implementation evidence. External WebApp targets in page copy require independent validation.
